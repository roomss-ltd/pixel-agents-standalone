# Suggested Commands

## Development
```bash
# Install dependencies
cd server && npm install
cd webview-ui && npm install

# Run server in dev mode
cd server && npx tsx src/index.ts

# Build server
cd server && npx tsc
```

## System utilities (macOS/Darwin)
- `git`, `ls`, `cd`, `grep`, `find` — standard unix commands
- Package manager: npm
